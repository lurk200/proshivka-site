# ПРОШИВКА v2

Новая витрина сервисного центра. Сейчас этап **визуала** (главная + галерея работ). Админ-панель — следующим этапом.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://127.0.0.1:5174/

## Структура клиента

- Главная: hero → услуги → галерея → контакты
- `/works` — полная галерея с фильтрами
- Мобильный нижний бар + кнопка «Написать»
